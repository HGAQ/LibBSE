# W 插值与二进制缓存

## 均匀细网格上的 q 去重

BSE 用 q = k₂ − k₁ 计算屏蔽相互作用。浮点减法可能把同一个物理 q
表示成略有不同的数字，从而重复执行 W 的 Fourier 变换。
程序现在自动识别完整的均匀细网格（包括平移网格和长方形网格），
用整数网格索引统一转移 q 的表示。识别容差为分数坐标 1e-10。
这不会把 q 近似到粗网格，不需要增加输入参数。
不完整、重复或不规则的网格保留原来的映射方式。

适用于使用均匀细网格的计算，特别是多个 k 点对对应同一个 q 的情况。
这是避免重复工作的优化；实际耗时改善需要用具体算例测量。

## 偶数粗网格的边界平均

```text
bse_w_boundary_average true
```

默认 false，仅支持静态屏蔽。偶数粗网格的实空间边界可以表示成
+N/2 或 −N/2；在原始粗网格 q 点两者等价，在新细网格 q 点的相位却可能不同。
此选项对这些等价端点取平均，奇数轴不变，原始粗网格上的 W 值不变。

当使用偶数粗网格插值到不同细网格，并希望避免单侧端点表示的影响时使用。
它会改变细网格上的插值值，应比较激发能和光谱并检查粗网格收敛性。
它不重算细网格屏蔽，不进行 Wigner–Seitz 重映射，也不修复 RI 电荷守恒。

## 静态完整 W 二进制缓存

```text
screened_format full_w_binary
screened_dir /path/to/static_full_w_cache
```

当已有同一体系、同一辅助基和粗网格的静态完整 W，且需要反复进行 BSE
计算时，可以使用此格式，避免每次解析大量文本数字。
普通文本 W 输入仍可继续使用；没有合格缓存时不需要打开此选项。
本功能只读取缓存，不会自动把现有文本转换或写成二进制文件。

缓存必须来自实际 omega=0 的计算，不能把最低非零频率重新标成零。
每个粗 q 点一个 `full_w_q_*.bin` 文件，必须覆盖完整粗网格；
文件名中的编号不决定 q，程序按文件头里的分数坐标匹配。
矩阵是原始辅助基顺序下、以 Hartree 为单位的完整 W，不能放 Wc 或 chi0。
读取后不会再加 V。缓存与当前 RI/KS 数据的辅助基含义和顺序必须一致，
尺寸检查无法证明基函数本身相同。

文件使用本机字节序，布局如下：

| 区域 | 内容 |
| --- | --- |
| 前 16 字节 | `LIBBSE_FULL_W_V1` 加一个 NUL 字节 |
| 接着 4 个 int32 | naux、nx、ny、nz |
| 接着 4 个 float64 | qx、qy、qz、omega_Ha |
| 64 字节头之后 | naux × naux 个 complex128，按行排列，每项实部在前、虚部在后 |

读取时检查文件尺寸、辅助基维数、粗网格尺寸、缺失/重复/离网格 q 点、
非有限数值、非零频率和矩阵厄米性。这是本地缓存格式，不能保证跨字节序平台通用。
读取后的 q→R 变换和后续细网格插值与完整 W 文本路径共用相同流程。
换格式本身不提高物理精度；复用前须确认缓存来源和计算设置仍匹配。

## 保留的接口修正

FHI-aims 速度矩阵与 LibRPA analytic wing 使用的行列约定相反。
现在仅在初始化 chi0 head/wing 时转置，并在正常结束或异常退出时恢复，
保证光谱计算继续使用原来的约定。原有 `chi0_headwing` 功能保留。

裸库仑 q 空间数据在 chi0→W 中仍需要使用。释放条件补上花括号，
使 chi0 路径保留该数据，其他不再需要的路径才清空。

长程 head 模型、head/wing 删除与参考补回、交换 Gamma 替换及固定算符
导入导出实验已移除。旧输入中的这些选项会作为未知参数报错，需删除后再运行。
